# 下载库顶部收敛

用户当前截图把传输、搜索、操作、排序、详情和筛选同时放在顶部，标题旁的筛选按钮还与工具栏属于同一类任务。此次只收敛这个工作区，不增加新功能。

## 改动

- 标题行保持标题与数量，只有实际存在的组合筛选才显示可清除摘要。
- 搜索右侧用一个“显示选项”面板整合排列方式、升降序与筛选。表头仍可直接排序；保存视图仍保留当前排序和筛选。
- 删除常驻“操作”按钮。快速操作由应用菜单“显示 → 快速操作…”和 ⌘K / Ctrl+K 进入。
- 空闲传输保留一个安静图标；有下载才显示计数和速度。临时文件限速仍可从传输面板找到。
- 保留稳定的两层布局、320px 搜索最大宽度、右上角详情开关，以及原有选中材质。弹层沿用短暂淡入和轻微位移，并支持减少动态效果。

1. **空闲下载库：通过。** 三个主题、740/820/980/1000/1020/1200/1440px 七个宽度，搜索和控制项没有越界，标题与表头保持原有两层布局。760px 以下仍沿用既有的 macOS 窗口按钮避让空间。
2. **排序和筛选：通过。** 改变排序与升降序后持久化正确；组合筛选不新增表头行；Escape 关闭面板后焦点回到入口。
3. **任务详情：通过。** 打开/关闭详情后列表纵向位置保持不变；保留已有选中材质。
4. **快速操作和搜索：通过。** 实际应用菜单入口、⌘F、Escape 清除搜索/退焦点均正常；原有快速操作流程与保存视图 CRUD 回归通过。
