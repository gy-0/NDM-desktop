## 临时文件限速

工具栏的传输状态可展开查看当前任务，并设置 15、30、60 分钟的临时文件限速。显示恢复时间，支持提前恢复；重载界面、重启和休眠后仍按截止时间核对。手动改值会结束原恢复计划，未确认或恢复失败会明确显示。

macOS 的现有引擎提供普通 HTTP 文件的默认单项上限，单项设置优先，因而使用“文件限速”名称。本功能不是跨协议共享的总带宽预算，Windows 暂不提供临时入口。详见[限速范围审查](../design/2026-09-12-bandwidth-scope-review.md)。

同时修复底层进度按大块回调停顿后跳跃的问题，限速等待期间按小片段写入并报告真实字节数。合并媒体的 HTTP 子下载会跟随默认限速恢复。排队及启动前的暂停不会再被迟到的启动回调覆盖。
