## 结论（一句话）

**不做整体付费，也不做订阅；做"免费够用 + 一次买断 Pro"的 Freemium。**
主推 **$24.99 一次性（个人，≤3 台 Mac）**，早期 **$14.99 早鸟** 换口碑基数。

## 为什么不是另外两个方案

| 方案 | 判定 | 理由 |
|---|---|---|
| 整体付费（无免费版） | ✗ 否决 | 品类里免费对手林立（NDM 原版、FDM、Motrix 全免费）。没有免费档 = 没有口碑入口，"Mac 免费 IDM"心智会被别人占走。Downie 式纯付费能成立靠的是 1000+ 站点的既有声誉，新产品没有这个资本。 |
| 订阅制 | ✗ 强烈否决 | 4K Download 的 $15/年 引发社区公愤 `[已查证]`；该品类订阅口碑为负。"一次买断、永久更新、无 nagware"本身就是差异化卖点。 |
| Freemium + 买断 | ✓ 推荐 | Folx/4K 验证了分层可行性；$15–30 是 Mac 下载器买断的心理价位带；与"诚实授权"叙事天然契合。 |

## 免费 / Pro 分界线

分界原则：**下载这件事本身永远免费**——加速、续传、浏览器接管、日常视频单集下载全部进免费档。Pro 卖的是"规模与画质"，不是"能不能用"。这样差评面最小，且与免费对手保持全面兼容。

| 能力 | 免费档 | Pro |
|---|---|---|
| 多线程分段加速、断点续传 | ✓ | ✓ |
| NDM Relay 浏览器接管 | ✓ | ✓ |
| 单个网页视频 / 文件下载 | ✓ | ✓ |
| 分类保存、限速、队列 | ✓ | ✓ |
| 无广告、无弹窗、无订阅 | ✓ | ✓ |
| 播放列表 / 频道整批下载 | 单次 ≤ 10 项 | 不限 |
| 4K / 8K 超清与高码率轨 | ≤ 1080p | 全画质 |
| 下载历史云同步（iCloud） | — | ✓ |
| 格式转换 / 音频提取 | — | ✓ |

> 与 `license.ts` 现有草案的差异：播放列表与超清在免费档保留"小额度试用"（≤10 项 / ≤1080p），而不是完全锁死——先让用户尝到价值，再为规模付费。这是对原草案唯一的修改建议。

## 让人愿意掏钱的顺序（重要）

价格不是第一推动力，**可靠性才是**：
1. 先把"YouTube/B站今天还能用吗"做成信任资产（失效快速修复 + 透明状态），这是全品类最大痛点 `[已查证]`；
2. 设计完成度撑住"值得付钱的样子"（对标 Downie/Things 3）；
3. 付费点出现在用户**正伸手要那个能力的一刻**（选了 2160p、粘贴了整个播放列表）→ 现有 ProModal 的 reason 机制就是为此设计的，方向正确；
4. 永远不用弹窗催购、倒计时、假折扣。

## 上线前必须补齐的工程项

1. **真签名激活码**：现 redeem 仅校验格式（`license.ts:56` 注释自认）。上线前需要 Ed25519 签名的 license 文件 + 内嵌公钥校验，防伪造。
2. **门禁接线**：从 `PRO_FEATURES` 统一门禁（架构已就位），在格式选择器（>1080p）、合集确认页（>10 项）、设置云同步/转换区挂 `requiresPro()`。
3. **支付与发货**：Paddle / LemonSqueezy 二选一（处理税务），webhook 签发 license 邮件。
4. **店外分发说明页**：视频能力无法上 MAS `[已查证]`，学 Downie 写清楚 FAQ。
5. **免费额度计数**：本地按月计数即可（不做账号系统，符合"轻授权"定位）。

## 风险与对策

- **盗码破解**：买断软件必然被破解。对策：心态上把破解当试用，重点防"顺手伪造"，不搞对抗性反调试（伤害正常用户）。
- **视频站点失效连坐**：Pro 主打卖点恰是最脆弱的功能。对策：站点适配层独立热更新（site-adapters 已模块化，可远端下发配置）。
- **早鸟价锚定**：$14.99 → $24.99 涨价要提前公告，避免"背刺"观感。
