# 文件口袋与已选文件抽屉 · 2026-09-14

紧凑卡片改版误将用户喜欢的文件口袋整体移除。本次恢复其层叠纸卡、悬停扇开与点击展开操作，并控制横幅高度，让它和默认窗口中的两整行下载卡片共存。单文件卡片仍是单个图标或真实预览，文件库仍连续滚动。

参考 [Sanyam Folder Stack](https://github.com/SanyamPunia/www/tree/f70a5c19680b26eec3b7586acbf9d751584f40d5/components/labs/folder-stack) 的抽出层次，以及 [Tab Overview](https://github.com/SanyamPunia/www/tree/f70a5c19680b26eec3b7586acbf9d751584f40d5/components/labs/tab-overview) 的紧凑入口展开方式，使用现有 React、Base UI 和 TanStack 依赖独立实现，没有复制参考源码、素材或坐标。

- 顶部文件口袋的收起横幅占高144px，标题与口袋标签使用中文；扇开的每张纸对应一条真实完成任务，仅有一个文件时只显示一张纸。
- 点击口袋可打开、预览或在访达中显示文件；Escape 关闭并返回入口焦点。搜索时让出空间，有大传输卡的列表视图不重复占用高度。
- 新增已选文件抽屉：批量操作栏中的层叠文件是核对当前选择的入口。展开后显示实际选中的文件名、类型、大小及状态；大批量选择只挂载可视附近的文件行。
- 原有批量暂停、继续、复制与删除逻辑保持；浏览选择清单本身不会执行任务操作。悬停区域固定，只有纸片移动，文字不随按压缩放；减少动态时直接呈现稳定状态。

界面验收使用独立 Electron 用户目录和私有引擎夹具，文件操作在 IPC 边界记录；安装后的真实下载单独验证。
