# 主下载区域：真实 Electron 缩放

继窄任务列表后，使用实际 Electron `webContents.setZoomFactor(1.25)` 检查主下载区域，避免把上一轮 CSS 可用宽度模拟当成真实缩放证明。

旧安装版在长文件名、详情打开时可复现标题把内部 grid 撑宽，速度/单位和暂停按钮越过主区域。修复为动画内容 grid item 允许收缩；主区域小于等于 420px 时，文件信息独占上行，速度或已保留字节与暂停/继续按钮位于下行。宽区域保持原有横向布局，背景进度及任务切换机制不变。

隔离 Electron 使用独立 support/ports，无历史任务复制。QA 的主进程 handler 在点击前替换为内存任务处理，快照也固定为该数据集；不会向真实用户任务发送暂停或继续。首次 QA 的后几组被隔离空 Host 快照清掉详情，因此最初“全部通过”不能作为六组详情证据；最终版本必须逐组断言详情仍打开。

截图通过 BrowserWindow.capturePage 获取完整原生窗口，避免 Playwright 在缩放后按 CSS viewport 裁掉图片右边。测试仍以 DOM 边界与元素不相交为主要证据。

## 实际结果

最终隔离 Electron 在 920/1024/1440 窗口、1.0/1.25 实际 zoom 的六组中均保持详情打开，标题/速度/单位/按钮无主区域越界或相互重叠。920＋1.25 下暂停态的保留字节及继续按钮同样可见；点击暂停、继续各产生一次对应 fixture task 的模拟 IPC。未改变真实任务。

288 项界面/脚本检查、类型检查和构建通过。`/tmp/ndm-hero-zoom-green/report.json` 与实际完整窗口截图已检查；PNG 1840×1800 匹配 920×900 内容区及 2× 屏幕倍率。旧安装包复现日志 `/tmp/ndm-hero-zoom-red.log`。这次证明 Hero 的这组六种状态组合，不扩大为全部界面或所有缩放比例已完善。

正式签名包在真实 Electron 重跑六组全部通过，详情每组保持打开，暂停态与两次模拟控制请求也通过；日志 `/tmp/ndm-hero-zoom-packaged.log`，报告及完整截图 `/tmp/ndm-hero-zoom-packaged/`。
