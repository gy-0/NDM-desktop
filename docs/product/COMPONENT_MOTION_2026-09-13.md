# Component motion · 2026-09-13

首批打磨覆盖任务动作、数量、添加下载弹窗和批量操作条。参考 Sanyam Lab 的交互方向，使用 NDM 已有的 Motion、Base UI 和 Lucide 独立实现；没有复制其组件源码或新增依赖。

- `TransferActionIcon` 在继续、暂停、下载、等待回执之间过渡。按钮尺寸、标签、禁用条件和失败反馈仍由原业务控制。录制保留“停止并保存”。
- `AnimatedCount` 用两个固定视觉层呈现数字切换，读屏只读取当前值。快速连续更新取消旧动画；CSS 时间值同时处理 `ms` 和压缩后的 `s`。
- Composer 的根组件保持挂载，由 Base UI 管理进入和离开；正文自然高度变化用 `ResizeObserver` 测量，底部操作栏保留在可滚动正文之外。
- 批量条在原网格区域内淡入淡出，任务列表不位移。退出的控件立即变为 inert，焦点回到搜索框。
- 共用一个动态偏好监听器；运行中开启“减少动态”会结束位移、旋转及高度动画。

## 验证

执行 `npm test`（435/435）、`npm run typecheck`、`npm run build` 和 `node scripts/qa-component-motion.mjs`。

生产构建运行于真实 Electron main/preload/renderer，使用私有 TCP 引擎夹具、合成任务和独立的用户目录、支持目录及端口。六组交互验证通过：

1. 等待回执期间显示忙碌；失败保留原任务状态，重试成功后切换动作。
2. 12 → 9 → 10 → 11 → 9 的连续数量变化捕获到 38 个中间帧，最终值及读屏值准确。
3. 雾昼主题、740 × 680 窗口：弹窗入场、选项高度变化、焦点约束和快速开关正常。
4. 深色主题下同样通过；两种主题的正文高度均从 138 px 过渡到 234 px，底部按钮完全位于窗口内，横向溢出为零。
5. 运行中切换减少动态：数字、等待图标及弹窗无位移或旋转。
6. 2,000 条合成任务仅挂载 16 行，末行可达，数量正确且无横向溢出。

退出后夹具两个端口均关闭、连接归零、renderer 错误为零。脚本在开始和结束比较构建指纹，避免把中途重建的结果混入证据。

这是 Electron 界面验收，不包含真实网络下载或已安装 macOS 应用的发布验收。本批未改下载引擎，也未替换 `/Applications/NDM.app`。
