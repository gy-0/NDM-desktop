# 下载恢复验收 · 2026-09-23

失败任务的主要操作现在直接进入恢复流程，列表、卡片和详情保持一致。移除详情中的手动直链替换表单。普通传输错误使用继续下载，不再默认清空进度后重试。

## 支持范围

- 现有 Relay 支持的抖音视频页面：自动读取浏览器来源，由用户选择版本，然后在原任务中恢复。
- yt-dlp：使用已保存的原网页和任务选项重新读取；需要登录时提供打开原网页和重新读取入口。
- 其他来源：明确提示暂不支持自动重新获取，提供原网页入口。不是全站自动恢复；未知的新直链重新捕获仍可能创建新任务。
- Chrome Web Store 是正式分发方向，本次不改变插件分发方式，也没有执行商店发布。

## 数据保护

新资源不被假定为旧片段的同一文件。有已有数据时先要求确认重新下载。确认后保留任务 ID、文件名和保存目录，原片段留在旧工作目录；新请求头、URL 和工作目录代次在同一事务中提交。旧恢复请求不能覆盖新代次。

旧片段保留会占用磁盘，用户明确移除任务时一并按归属记录清理。原有 renewURL 的同源、片段保护限制仍然保留。
