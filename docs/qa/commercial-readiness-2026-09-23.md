## 已实现和验收的产品体验

| 用户任务 | 当前结果 | 证据与边界 |
| --- | --- | --- |
| 第一次下载 | 欢迎页进入添加表单，突出链接与目录，高级选项收起；保留草稿和键盘焦点 | 实际隔离 Electron 完成 512 KB 下载；不等于新用户成功率调查 |
| 看清操作和状态 | 三套主题统一蓝色；调整表单宽度、弱文本及小屏官网排版；减少动态效果生效，异步设置保存保留键盘操作位置 | 界面截图、键盘操作、指定布局验收；不作全面无障碍认证 |
| 从浏览器接管 | 真实握手与版本判断；连接重启和重复投递不重复建任务；正式包提供商店入口配置 | Relay 协议与真实 Host 验收；商店条目和真实商店安装尚未完成 |
| 下载中断后继续 | 已验证网络四次中断续传、启动失败有界重试、重启后的非零 Range 续传；旧普通文件任务重启显示保留进度 | 最终文件逐字节或 SHA 核对；不承诺所有已有进度的网络故障都有固定重试次数 |
| 资源已经变化 | 普通重试不混拼新旧文件；明确确认重新下载后保留任务、目录、旧检查点 | 真实 Host 和旧数据不变断言；任意文件网页的关联重新捕获仍未实现 |
| 磁盘问题后恢复 | 实际 APFS 磁盘耗尽后继续；重挂载设备号改变仍能验证同卷身份并恢复 | 实际隔离映像与完整文件核对；不自动寻找改变挂载路径的磁盘 |
| 不兼容保存目录 | 新普通文件任务在开始前要求选择兼容目录，同任务继续 | 真实 ExFAT 映像、重启和 CUA 操作；这不是 ExFAT 直接下载支持 |
| 下载完成后拿到文件 | 打开、定位、安装结果、详情字段和侧车文件操作都有等待与失败反馈 | 文件交付实测和模拟系统失败的渲染器验收；两种证据分别记录 |
| 更新与求助 | 检查更新、报告问题、白名单诊断预览及主动保存；失败可重试 | 真实 Electron 诊断导出与更新网络验收；无任务网址、文件名、Cookie 等诊断外传 |
