# 08 · UI 窗口与交互

## 应用形态

- `LSUIElement = true`：菜单栏常驻  
- `NeatStatusItemView` + `statusMenuItemClicked:` / `popUpStatusItemMenu:`  
- 单实例：`NeatDownloadManager is already running.`  
- 前置提示：`You can always bring NeatDownloadManager to front by clicking on Status Menu Item.`

## 主窗口（AppDelegate）

### 控件

- `downloadsTable`（`NeatTableView`）
- `categoryOutline`（状态 × 类型树，`NeatTreeNode`）
- `toolBtnResume` / `toolBtnStop` / `toolBtnDelete`
- 拖放：`NSDraggingDestination` 系列 → `handleNewUrl:` / `URLFromPasteboard:`

### 分类树

节点：`initWithCategory:aStatus:aTitle:`  
过滤：`loadRecords:category:sortOrder:activeWindows:`  
`currentStatus` / `currentCategory` / `allStatus`

### 操作

- `doubleClick:` 打开进度/属性  
- `resumeDownload:` / `stopDownloads` / `deleteDownloads` / `reDownload:`  
- `openFile:` / 访达定位  
- `showPropertiesWindow:`  
- `application:openURLs:` 等外部打开 URL  

## 下载进度窗（NeatDownloadWindow）

### 显示

- `downloadProgress`（`NeatProgressBar`）
- `segmentsProgress`（`NeatSegmentsProgressBar`）— 分段色块  
- `connectionsTable` + `connectionsComboBox`  
- `lblStatus` `lblDownloadedBytes` `lblRemainTime` `lblResumable`  
- `lblBandWidth` / `txtBandWidth` / `lblCurrentBandWidth`  
- `lblSegmentsInfo`  
- `btnPauseResume` `btnConnectionsApply`  
- `chkRememberConnections` `chkRememberBandWidth` `chkCompletionDialog`  
- `imgIcon`

### 引擎回调

- `onDownloadWindowProgress:progressInfo:`
- `onDownloadWindowNotify:senderWindow:extraInfo:`
- `handleEngineNotify:` 等

### MKV 变体额外

- 视频/音频两套 table、progress、status、downloaded 标签  
- `getRemainedTimeStr:curBandWidth:`

## Wait 窗口

扩展在 `waiting` 状态时：用户确认 URL（`hitTitle`）后 `handleWaitWindowOk` / Cancel。

## 自定义控件

- `NeatProgressBar` / `NeatSegmentsProgressBar`：`addNormalSegments:shouldDraw:` `addTSSegments:shouldDraw:` `drawSegments`
- `NeatCustomButton`
- `NeatTextField` / `NeatTextFormatter`（数字输入）
- `NeatTableView`
