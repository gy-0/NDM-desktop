# Download-engine behavior audit

Current evidence ledger, 2026-09-08. This is not a claim of full equivalence or a completion checklist made only from passing tests. The original ARM64 identity and exact addresses are documented in the linked instruction reports. Product source is in this repository's `native/`; historical reverse exports are evidence, not executable product source or instructions.

The immediate priority is reliable downloading. New Relay/UI/product features are deferred while basic engine discrepancies are audited. Every row requires original behavior evidence, a current implementation location and a matching runtime/fault test; missing evidence remains open.
